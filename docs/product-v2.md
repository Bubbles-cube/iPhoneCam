# 泡泡直播助手 v2 產品設計（MVP）

> 方法來源：馬克《我的 AI 編程全流程》——先定 MVP 邊界（做什麼／不做什麼），再寫技術方案，再實作。
> v1（`iPhoneCam/` 舊資料夾，Git 已快照）功能驗證通過但補丁疊補丁，v2 推倒重寫，只帶走「已驗證的知識」，不帶走屎山。

## 一句話

手機鏡頭 → Wi-Fi → PC 虛擬攝像頭 → OBS／Discord，低延遲、切檔不死、狀態誠實。

## 做什麼（MVP 範圍）

### 手機端（Android）
- 預覽：後鏡＋前鏡切換，直向鎖定，cover 填滿置中，待機圖（無畫面時）。
- 編碼：H.264 only，CBR；檔位 720P（960x720）／1080P（1440x1080），FPS 30／60，碼率 4M／8M（設定頁滑桿 1～40M 可調）。
- 傳輸：TCP 控制（hello／video_params／codec_config／idr_request／set_video）＋ UDP 影像（分片＋NACK＋3 秒看門狗回 TCP）＋ UDP 信標（能力跟檔位）。
- 方向：陀螺儀 rot＋鏡像＋2 秒心跳，PC 為主跟隨；本機預覽不轉。
- 保命機制（v1 血淚，全部保留）：drain 代號防重入、session 失敗自動降檔（1080P↔720P、60 轉 30）、亮屏＋WiFi 鎖、過熱降碼率、crash 記錄、AE 快門鎖定。
- 誠實狀態：LIVE＝真有畫面才亮；成功留「預覽就緒」一行（含超採樣／框尺寸實測）。

### PC 端（WPF）
- 儀表板：即時預覽、裝置搜尋＋手動 IP、解析度／FPS 下拉（兩檔）、IDR 按鈕、截圖、存檔開關。
- 解碼：ffmpeg 子程序，D3D11VA 硬解優先、失敗退軟解；幀計數＋CPU 顯示。
- 濾鏡：第一版不做（eq 五預設一起砍，只留乾淨預覽；使用者拍板）。
- 虛擬攝像頭：NV12 直通、跟串流換畫布、斷訊凍結上一幀；OBS 按鈕、診斷複製。

## 不做什麼（第一版明確排除）

- 美顏 UI（雙端全砍：引擎從沒存在過，滑桿只是擺設）。
- 影像濾鏡（eq 五預設：第一版只留乾淨預覽）。
- 超採樣（ImageReader 丟幀流：效果沒驗證過，又貴又燙，砍）。
- ABR 碼率階梯（先固定碼率；爛線靠 UDP＋NACK＋看門狗撐，穩定後再說）。
- 2K／4K 檔、HEVC（4K 在真機開不起來是事實；等 MVP 穩了再往上加）。
- iOS 端、USB 傳輸、RTSP／SRT、麥克風（純視訊產品）。

## 驗收標準（人工驗證用，全部要過才算交付）

1. 開播中切 720P↔1080P、切 30↔60：不死、不凍超過 2 秒、狀態列寫對。
2. PC 預覽與 OBS 同畫面，連續 5 分鐘不斷流。
3. 手機轉向：PC 2 秒內跟正；斷 Wi-Fi 再回來：3 秒內自動回 TCP 不死。
4. 手機本機預覽：各檔填滿無變形（對 `預覽就緒` 行的視／buf／倍率）。
5. 雙端建置 0 警告 0 錯誤；每完成一檔 commit 一次（Git）。
